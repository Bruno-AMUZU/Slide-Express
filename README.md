# Slide Express — site vitrine

Site vitrine de **Slide Express**, studio de création de présentations professionnelles (PowerPoint, Google Slides, Keynote).

## Contenu

Le site tient dans un seul fichier, `index.html`, qui regroupe le HTML, le CSS et le JavaScript. Aucune installation n'est nécessaire.

Il comprend un comparateur avant / après interactif, une galerie de réalisations filtrable avec visionneuse, la présentation des services, la méthode de travail, les tarifs, une FAQ et des liens vers la page Fiverr.

## Voir le site en local

Ouvrez simplement `index.html` dans votre navigateur.

## Mettre en ligne avec GitHub Pages

1. Dans le dépôt, ouvrez **Settings → Pages**.
2. Sous **Build and deployment**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
3. Cliquez sur **Save**. Le site sera disponible après une ou deux minutes à l'adresse `https://<votre-nom-utilisateur>.github.io/<nom-du-depot>/`.

## Personnaliser

- **Lien Fiverr** : remplacez `https://www.fiverr.com/slideexpress` par l'adresse de votre profil (rechercher-remplacer dans `index.html`).
- **Tarifs** : section `id="tarifs"`.
- **Couleurs** : variables CSS en haut du fichier (`--navy`, `--gold`, etc.).
